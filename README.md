# Southeastern Pet Vacc Demo

Frontend concept demo for improving schedule visibility and customer accessibility for a local mobile veterinary clinic.

## Goals
- Replace repetitive Facebook schedule posts with a cleaner mobile-first experience
- Improve readability and navigation
- Organize recurring locations and pricing
- Create a responsive layout optimized for phone users

## Features
- Responsive design
- Schedule filtering
- Mobile-first UI
- Service pricing organization
- Visit preparation section
- Real-world clinic imagery
